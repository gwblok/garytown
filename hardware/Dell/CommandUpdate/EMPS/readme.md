# Dell Command Update Scripts

> **This folder is no longer maintained.**

New development for the Dell Command Update functions has moved to the [OEMWrapPS](https://github.com/gwblok/OEMWrapPS) repository.

OEMWrapPS is available as a PowerShell module from the [PowerShell Gallery](https://www.powershellgallery.com/packages/OEMWrapPS).

```powershell
Install-Module -Name OEMWrapPS -Repository PSGallery
Import-Module OEMWrapPS
```

Please use the OEMWrapPS repository for current code, updates, and documentation.
